# Node.js Practical Projects

This ZIP contains two separate beginner-friendly Node.js + Express projects.

## Requirements
- Node.js and npm installed

## Task 1: Dynamic UI
1. Open a terminal in the `Task1` folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000

## Task 2: Student Profile
1. Open a separate terminal in the `Task2` folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3001

Run each project from its own folder. Stop a running server with Ctrl+C.
